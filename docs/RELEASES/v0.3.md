# v0.3 — Voxel inhabitants and rule-based ecology

## Included
- Eight original pixel-block inhabitants with unique starting tiles, names, roles, and colors.
- Deterministic placement from the selected world seed.
- Simple local policies for exploration, food seeking, foraging, and resting.
- Bounded hunger/energy state, agent age and movement steps, and inspectable event summaries.
- Click an inhabitant to inspect its current action, coordinates, hunger, energy, and movement count; click terrain to return to tile details.
- Visible population count and simulation tick.
- Local-only simulation; no model/API calls, accounts, or backend.

## Explicit limitations
- Agent movement and needs use transparent scripted rules, not learned policies.
- Food/vegetation markers are renewable for prototype purposes. Resource depletion, reproduction, hazards, social behavior, persistent saves, and long-term ecology are not included.
- The simulation is deterministic for a given world and run state, but does not implement a Neural Cellular Automaton.
- The learned NCA core remains planned for v0.4. LLM world authoring and DOTS integration remain future milestones.
- These scripted agents are not conscious and should not be described as such.

## Acceptance checks
- Node tests verify deterministic placement, unique land-tile starts, bounded state, immutable step results, seeded replay, and input limits.
- CI checks syntax, test suite, required DOM controls, accurate capability wording, and isolated hosting documentation.
- Browser-level visual and interaction testing still needs a real browser/device pass.
