# v0.4 — NCA simulation core

## Included
- Bounded 2D cellular field aligned to the terrain grid.
- Five state channels: alive, pigment, nutrient, signal, and age.
- Per-channel local perception: cell center, eight-neighbor mean, and Laplacian response.
- Shared neural update network with a 15-feature input, 12-unit tanh hidden layer, and 5-channel output.
- Deterministic weight initialization by world seed with a stable initialization prior; reproducible per-cell update masks.
- Canvas overlay with show/hide control, a single-step button, reset-to-seed, and live active-cell/tick metrics.
- The NCA field is distinct from the inhabitants' scripted movement policy.

## Explicit limitations
- The network weights are initialized, **not trained**. No training objective, gradient-descent pipeline, target morphology, or learned-organism claim is included.
- The NCA is not a general intelligence and does not imply consciousness.
- The browser currently executes NCA updates on the main thread; performance should be profiled and a worker added before increasing field size.
- Browser-level visual and interaction tests on real desktop/mobile devices are still required.
- LLM world building and DOTS learning integration remain future milestones.

## Acceptance checks
- Tests cover channel bounds, deterministic initialization, unchanged input snapshots, deterministic replay, and parameter validation.
- CI checks syntax, unit tests, required NCA controls and metrics, and explicit disclosure that weights are untrained.
