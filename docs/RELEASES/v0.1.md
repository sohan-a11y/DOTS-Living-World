# v0.1 — Web foundation

## Included

- Responsive, accessible landing page with original visual identity.
- Procedural pixel-field preview with a pause/resume interaction.
- Clear status labels: the preview is decorative and is not an NCA execution.
- Explicit architecture boundaries for LLM, DOTS, and NCA.
- Public repository and staged release roadmap links.
- Dependency-light local server, unit tests, and GitHub Actions validation.
- No runtime API endpoints, authentication, analytics, or secrets in this milestone.

## Not included yet

- Real NCA training or inference.
- Humanoid/voxel agents.
- LLM provider integration or prompt-to-world compiler.
- DOTS runtime integration.
- User accounts, saved worlds, or a shared backend.
- Production-scale load test.

## Acceptance criteria

- JavaScript syntax passes and tests verify deterministic, bounded field generation.
- Page entry points and the v0.1/NCA disclaimer are verified in CI.
- App is responsive and supports reduced-motion preferences.
- The repo is deployable independently, with no Artifex custom domain attached.
