# v0.2 — Interactive world viewer

## Included
- Three deterministic terrain presets: Moss Basin, Crystal Ridge, and Ashen Frontier.
- Seed input and generation button for reproducible terrain.
- Pointer drag and keyboard controls to pan.
- Mouse-wheel and button controls to zoom, plus reset view.
- Pause/resume and selectable visual pulse speed.
- Tile selection and terrain/feature inspector.
- Responsive controls and reduced-motion support.
- Local-only viewer; no LLM/DOTS API calls required.

## Explicit limitations
- This release is a procedural world viewer, not a trained Neural Cellular Automaton.
- No humanoid or autonomous agents are present; those are planned for v0.3.
- No LLM world compiler or DOTS learning service is connected yet.
- The visual pulse is view animation, not a simulation tick or evidence of learning.

## Acceptance criteria
- Deterministic generation for a given preset and seed.
- Seed range, world dimensions, and preset validated.
- Tests cover deterministic generation, terrain bounds/counts, and tile inspection.
- CI verifies syntax, tests, required DOM controls, and that NCA limitations remain explicit.
