# v0.5 — Constrained world specification builder

## Included
- Plain-language world instruction box.
- Deterministic local compiler for supported terrain presets, seed, inhabitant count, NCA seed radius, NCA update rate, and NCA overlay/engine toggles.
- Strict versioned JSON schema; unsupported keys and out-of-range values are rejected.
- JSON preview and explicit apply action so changes can be reviewed before regenerating the world.
- Compiler explanations show which settings were recognized or preserved.
- No server calls, API secrets, account requirements, or generated code execution.

## Explicit limitations
- This release does **not** connect an LLM. Phrase recognition is deterministic and covers only documented keywords/fields.
- Unsupported text is ignored rather than interpreted by a general model. The compiler is not a substitute for natural-language understanding.
- A server-side LLM endpoint, response validation, rate/cost limits, and a local fallback remain to be implemented.
- NCA weights remain untrained, and voxel inhabitant behavior remains scripted.

## Acceptance checks
- Tests cover deterministic compilation, supported preset mapping, option extraction, strict key validation, length/range checks, and NCA toggle behavior.
- CI checks syntax, tests, required builder controls, and explicit disclosure that the LLM endpoint is not connected.
